# Social Media Assets

Dieses Repository enthält ausschließlich Bild- und Videomotive für
Social-Media-Postings (Facebook/Instagram) der Rehsearch GmbH.

Kein Code, keine Konfigurationsdaten, keine Personen- oder
Kandidatendaten. Bilder werden über raw.githubusercontent.com als
stabile, nicht ablaufende URL für scripts/posten-meta.mjs im
Schwesterprojekt rehsearch-social eingebunden.
